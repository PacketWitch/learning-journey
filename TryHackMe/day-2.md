# TryHackMe — Introduction to Defensive Security

## Overview

Completed the TryHackMe **Introduction to Defensive Security**
room as part of my cybersecurity learning journey.

## Objective

Learn the fundamentals of defensive cybersecurity and understand
how defenders identify, investigate, and respond to security threats.

## What I Learned

- What defensive security means
- The role of cybersecurity defenders
- Security monitoring
- Threat detection
- Incident response
- Digital forensics
- Security Operations Centres (SOC)
- How defenders investigate suspicious activity

## Key Takeaways

Defensive security focuses on protecting systems, networks,
applications, and data from attacks.

A defender's workflow can be thought of as:

Detection
↓
Investigation
↓
Response
↓
Recovery
↓
Prevention
